千葉県南房総市和田町、白渚ポイント目の前のサーフショップ **SPLASH** のオリジナルブランド **RIPSTIX** の公式サイトです。

運営：株式会社LTR（〒299-2711 千葉県南房総市和田町白渚586-2 / TEL 0470-47-4334）

**公開ページ（GitHub Pages）：https://k-okada-lang.github.io/ripstix/**

## 主な機能

| 機能 | 内容 |
|---|---|
| ボードのカスタマイズ | 5タイプ（グラベラー・フィッシュ・ショート・ミッド・ロング）、サイズ、テール、フィン、カラー、ロゴ位置（デッキ・ボトム） |
| 3D ビューア | 回転・縦横の切り替え、実寸に基づくフィン形状、3D 上でのロゴ配置、身長との比較、スプレー塗装の演出 |
| オーダーシート | PDF / PNG で保存（透かし入り） |
| 会員機能 | メールアドレスとパスワードでの会員登録・ログイン、パスワード再設定（確認コードをメール送信）、マイページ（保存したボード・注文履歴） |
| 管理画面 | 顧客管理（名前・フリガナ・電話番号で検索）、注文状況の更新、店頭のお客さまと過去の注文の登録、スタッフメモ、CSV 書き出し |
| 情報ページ | ライダー紹介、Instagram 作品、修理（リペア）案内、アクセス（Google マップ）、会社概要、プライバシーポリシー |
| SEO | コラム記事12本、構造化データ（店舗情報・FAQ・記事）、サイトマップと robots.txt の自動生成 |

## フォルダ構成

```
docs/                   ← GitHub Pages 用（静的版・会員機能なし）
public_html/            ← サーバーの公開フォルダにそのまま置く中身
├── index.php           トップページ（サイト本体）
├── api.php             会員・注文・管理画面の API（PHP + SQLite）
├── column/             コラム記事（12本）
├── img/                写真
├── private/            設定とデータ（.htaccess で外部から閲覧不可）
│   ├── config.php      ← 公開前に書き換える設定
│   └── seo.php         正式な URL を返す共通処理
├── sitemap.php / robots.php   sitemap.xml・robots.txt を自動生成
├── privacy.html        プライバシーポリシー
├── .htaccess           https への統一・保護・キャッシュ設定
└── favicon.svg / apple-touch-icon.png / ogp.jpg
```

## 動作環境

- PHP 8.1 以上（pdo_sqlite、mbstring）
- Apache（.htaccess が使えること）／エックスサーバーで動作する想定
- データベースは SQLite（`private/ripstix.sqlite` が初回に自動作成されます。MySQL の設定は不要）

## 公開手順（エックスサーバー）

1. サーバーパネルでドメインを追加し、無料独自 SSL を有効にする。PHP を 8.1 以上にする。
2. このドメインのメールアドレス（例：`info@ドメイン`）を作成する。
3. `public_html/private/config.php` を書き換える。
   - `ADMIN_EMAILS` … 管理画面に入れるメールアドレス
   - `MAIL_FROM` … 2 で作ったメールアドレス
   - `SHOP_NOTIFY_EMAIL` … 新しいオーダーのお知らせ先
   - `SITE_URL` … 正式な URL（例：`https://ripstix.jp/`）
4. `public_html/` の中身を、サーバーの `public_html` にアップロードする（`.htaccess` を忘れずに）。
5. `ADMIN_EMAILS` のアドレスで会員登録すると、そのアドレスに確認コードが届きます。マイページの「管理者の確認」に入力すると、メニューに「ADMIN」が表示されます（ほかの人が先にそのアドレスで登録しても、メールを受け取れない限り管理者にはなれません）。
6. Google Search Console に登録し、`sitemap.xml` を送信する。

## セキュリティ

- パスワードは `password_hash()`（bcrypt）で保存し、平文は残しません。
- ログイン5回失敗で5分ロック、IP ごとの試行回数制限、CSRF 対策、HttpOnly / Secure Cookie。
- お客さまは自分のデータのみ閲覧可能。注文の状況・日時・番号はサーバーが決め、変更は管理者のみ。
- 管理者は、ADMIN_EMAILS のアドレスに届く確認コードで本人確認できたアカウントだけ。
- パスワードを変更・再設定すると、ほかの端末のログインは自動で解除されます。
- 確認コード用の秘密鍵は初回アクセス時に `private/secret.key` へ自動生成されます（リポジトリには含めません）。

## リポジトリに含めないもの

`.gitignore` で次のファイルを除外しています。サーバー上で自動的に作られる、会員データや秘密情報です。

- `public_html/private/ripstix.sqlite`（会員・注文・顧客データ）
- `public_html/private/secret.key`（秘密鍵）
- `public_html/private/*.log`（動作確認用のログ）

**会員データのバックアップは、サーバーから `ripstix.sqlite` をダウンロードして保管してください。GitHub には上げないでください。**
