サーフボードのフィンの種類とセッティング｜シングル・ツイン・トライ・クアッドの違い

2026.10.30　文・RIPSTIX / SPLASH

フィンは小さな部品ですが、ボードの乗り味を大きく左右します。本数と配置（セッティング）の違い、フィン選びで見るべき数値を、初めての人にもわかるように整理しました。

フィンセッティングの種類

セッティング特徴合うボード
シングル大きなフィン1本。ゆったり大きなターン、安定した直進。ロングボード、ミッドレングス
2+1センターのフィンに小さなサイドを2本。シングルに粘りを足す。ロングボード、ミッドレングス
ツイン2本。軽く速く、テールが流れる自由な乗り味。フィッシュ、レトロ系
トライ（スラスター）3本。ホールドと操作性のバランスが良く、最も一般的。ショートボード全般
クアッド4本。小波ではスピード、掘れた波ではホールド。ショートボード、フィッシュ
5フィンプラグを5つ付け、トライとクアッドを付け替えられる。1本でいろいろ試したい人

フィン選びで見る3つの数値

  • ベース：ボードに付く部分の長さ。長いほどドライブ（加速）が効きます。
  • デプス：水の中に入る深さ。深いほどグリップし、浅いほど滑らせやすくなります。
  • スイープ（レイク）：後ろへの寝かせ具合。寝ているほど大きな弧のターン、立っているほど小回りになります。

※ 用語の定義は FCS のフィン用語解説を参考にしています。

たとえば、トライフィンの定番 FCS II Performer（M）はベース約4.37インチ・デプス約4.55インチ・スイープ33.7°。ロングボード用の FCS II Pivot 7" はデプス約7インチと深く、ツインの Modern Keel はベースが約6.4インチと長いのが特徴です。RIPSTIX の3Dカスタム画面では、これらの公表値をもとにフィンの形を再現しています。

フィンシステム（FCS・FUTURES）

フィンをボードに取り付ける仕組みには、プラグ式（FCS II など）とボックス式（FUTURES など）があります。どちらのシステムでボードを作るかで、使えるフィンが決まります。今持っているフィンがあれば、それに合わせて作ると無駄がありません。

迷ったときの選び方

  • はじめての1本、オールラウンドに → トライ
  • 小さい波で速さが欲しい → ツイン、クアッド
  • ゆったり大きく乗りたい → シングル、2+1
  • いろいろ試したい → 5フィン

テールとの相性はテールの種類と乗り味で、フィンやフィンボックスが壊れたときはサーフボード修理ガイドをご覧ください。

よくある質問

フィンは何本がいいですか？

迷ったら3本（トライ）が最もオールラウンドです。小波で速さを求めるならツインやクアッド、ゆったり乗るならシングルや2+1が向いています。

FCSとFUTURESのフィンは共通で使えますか？

取り付け方式が違うため、基本的に共通では使えません。ボードを作るときに、どちらの方式にするかを決めます。
