サーフボードのテールの種類と乗り味｜スカッシュ・スワロー・ラウンドピン・ダイヤモンド

2026.10.30　文・RIPSTIX / SPLASH

テールはボードの「最後に水が離れる場所」。形によって、ターンのキレ、ホールド感、スピードの出方が変わります。代表的なテールの特徴を一覧で紹介します。

テールで何が変わるのか

基本の考え方はシンプルです。テールの面積が広く角があるほど、浮力と反応の良さが増し、小さな波で走りやすい。逆に、テールが細く丸いほど、水をしっかりつかんで、大きく速い波でもホールドが効くようになります。

代表的なテールの種類

テール形乗り味合う波
スカッシュ四角の角を落とした形反応が良く、オールラウンド。ショートボードの定番。腰〜頭
ラウンドスカッシュスカッシュをより丸くした形スカッシュよりなめらかにつながるターン。腰〜頭
スクエア角ばった形キレのあるターン。面積が広く浮力も出る。膝〜胸
スワロー燕の尾のように割れた形幅のあるテールでも水をつかみやすい。フィッシュの定番。膝〜胸
ダイヤモンド菱形に角をつけた形スカッシュとピンの中間。軽快さとつながり。腰〜胸
ラウンドピン細めで先が丸い形大きく伸びのあるターン。ホールドが効く。ミッドレングスにも人気。胸〜頭以上
ピン細くとがった形最もホールドが強い。大きく速い波向け。頭以上

※ テールの分類と特徴は、SurferToday のテール解説などの一般的な考え方をもとにしています。実際の乗り味は、テールの幅・ロッカー・レールの形との組み合わせで変わります。

テールと他の要素の組み合わせ

テールは単独で決めるものではありません。たとえばラウンドピンでも、幅を広くとればミッドレングスらしい安定感が出ますし、スワローでもロッカーを強めればキレのある動きになります。フィンのセッティングとの相性も大切です。

迷ったら

  • 小さい波が多い → スクエア、スワロー、スカッシュ
  • いろいろな波に一本で → スカッシュ、ラウンドスカッシュ
  • 大きく伸びやかに乗りたい → ラウンドピン

RIPSTIX のカスタム画面では、テールを切り替えてボードの形がどう変わるかを見比べられます。

よくある質問

スカッシュテールとラウンドピンはどちらがいいですか？

よく行く波によります。腰〜頭の波でオールラウンドに使うならスカッシュ、胸以上の波で大きなターンをしたいならラウンドピンが向いています。

スワローテールは初心者でも扱えますか？

スワローテールのフィッシュは浮力があり小波で走りやすいので、中級へのステップとして人気です。テールが流れやすい癖があるため、乗る波を相談して選ぶと安心です。
