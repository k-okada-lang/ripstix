Board Repair

REPAIR修理も、ここで。

削るだけじゃなく、直すのもシェイパーの仕事。小さな凹みから、折れたボードまで。ボードのつくりを知り尽くしたシェイパーが、一本ずつ状態を見て修理します。RIPSTIX 以外のボードも、まずはご相談ください。

  • ディング（凹み・小さな穴）岩や板どうしの接触でできた凹み・穴をふさぎ、水が入らないように仕上げます。
  • クラック（割れ）・水漏れひび割れから入った水を抜いて乾かし、ガラスを巻き直します。
  • 折れ（スナップ）2つに折れたボードをつなぎ、補強して乗れる状態に戻します。
  • レール・ノーズ・テールの欠け欠けた部分をフォームから作り直し、元のラインに合わせて削ります。
  • フィンボックス・プラグ割れたフィンボックスやプラグの交換・打ち直しをします（FCS・FUTURESなど）。
  • デラミ（剥がれ・浮き）表面のガラスとフォームが剥がれてふくらんだ部分を修理します。
  • リーシュカップ抜けた・割れたリーシュカップの交換をします。
  1. 見せるInstagram の DM に傷の写真を送るか、お店に持ってきてください。
  2. お見積もり状態を見て、修理の方法・料金・期間をご案内します。
  3. 修理水抜き・乾燥から、仕上げの磨きまで行います。
  4. お渡し店の目の前は白渚ポイント。直したボードでそのまま海へ。

傷に気づいたら、早めにご相談ください傷から水が入ったまま乗り続けると、中のフォームが傷んで修理が大きくなります。真水で流してよく乾かし、海には入らずにお持ちください。料金と期間は、傷の大きさ・場所・ボードの素材（PU / EPS など）によって変わります。

よくある質問

カスタムサーフボードはどうやって頼めばいいですか？

お店で直接、または Instagram の DM でご相談ください。身長・体重、サーフィン歴、よく行くポイント、今のボードを教えていただければ、シェイパーが一緒に仕様を決めます。サイト内のカスタム画面で作ったオーダーシートを見せていただくと、話がスムーズです。

初心者でもカスタムボードを作れますか？

作れます。体重やレベルに合った浮力・長さで作れるので、初心者や中級者ほどメリットがあります。

世界に一つだけのデザインにできますか？

できます。カラーは一本ずつの手仕事のため、同じ柄は二度とできません。ロゴの位置や色も選べます。仕上がりは気温・湿度・塗りの回数・クロスの質で変わるため、画面と完全に同じにはならない点はご了承ください。

価格と納期はどのくらいですか？

モデル、サイズ、素材、カラーなどの仕様によって変わります。ご希望をうかがったうえでご案内します。

サーフボードの修理もできますか？

できます。ディング（凹み・穴）、クラック（割れ）、折れ、フィンボックス・プラグ、デラミ、リーシュカップなどの修理を受け付けています。RIPSTIX 以外のボードもまずはご相談ください。

お店はどこにありますか？

千葉県南房総市和田町白渚586-2、白渚ポイントの目の前です。富津館山道路「富浦IC」から車で約20分、JR内房線「和田浦」駅から徒歩約25分です。
